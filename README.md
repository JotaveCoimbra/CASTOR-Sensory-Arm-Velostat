# CASTOR Sensory Arm with Velostat Sensor 🤖

This repository is dedicated to developing a sensory system for the CASTOR social robot's arm, using the Velostat sensor. The goal is to integrate pressure sensors (Velostat) to monitor the arm's physical interactions with the environment and users, enhancing human-robot interaction. 🤝

## Project Description 🌟
The project aims to implement a sensory system on the CASTOR robot's arm using Velostat pressure sensors to capture physical interaction with the environment. These data will be used to improve the robot's response accuracy during interactions, enabling more natural and responsive behavior. 🦾

This project is part of the ongoing development of assistive and social robots with enhanced sensory interaction capabilities.

## Objectives 🎯
- Develop the circuit to read Velostat sensors to detect pressure. 💡
- Integrate Velostat sensors into the CASTOR robot's arm. 🦾
- Create an interface to visualize real-time data collection. 📊
- Improve the robot's physical interaction with users. 🤗
